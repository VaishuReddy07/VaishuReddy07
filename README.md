## 📌 Featured Projects

### 🩺 [CareSlot: Appointment Booking & Practice Management](https://github.com/VaishuReddy07/CareSlot)
A full-stack practice management demo for scheduling appointments and managing everyday clinic workflows.

- 🗓️ React and TypeScript dashboard for appointments, patients, clinical notes, availability and analytics
- 🔐 Spring Boot and PostgreSQL API with JWT integration, audit events and database-backed protection against overlapping bookings
- 🤖 Optional Claude API support for visit-note drafts that practitioners review before use
- 🐳 Docker Compose setup and GitHub Actions checks, including a 25-request booking concurrency check

`Java 21` `Spring Boot` `React` `TypeScript` `PostgreSQL` `Docker` `GitHub Actions` `Claude API`

### 🚌 [Urban Move: Smart Mobility Platform](https://github.com/VaishuReddy07?tab=repositories)
Full-stack platform that helps city transport operators track vehicles, plan routes and manage users through centralized workflows.

- 🔌 REST APIs with **Java 17 and Spring Boot** for vehicle, route and user operations
- 🔐 **JWT authentication** and role-based access control with Spring Data JPA, MySQL and Flyway
- 📖 Modular backend documented with **Swagger/OpenAPI**, with Dockerized local development

`Java 17` `Spring Boot` `Spring Security` `MySQL` `Flyway` `Swagger` `Docker`

### 💰 [Expense Tracker: Full-Stack App](https://github.com/VaishuReddy07?tab=repositories)
End-to-end platform to record, categorize and understand personal spending.

- ⚛️ Spring Boot REST APIs and a **React** frontend for CRUD operations and user-specific data
- 🔐 JWT authentication and **PostgreSQL** persistence
- 📈 **Recharts** visualizations of spending patterns, with the whole app containerized in Docker

`Spring Boot` `React` `PostgreSQL` `JWT` `Recharts` `Docker`

### 🌦️ [Weather Dashboard: React App](https://github.com/VaishuReddy07?tab=repositories)
Responsive dashboard with current conditions, hourly temperatures and five-day forecasts.

- 🌐 Live data from the **OpenWeatherMap REST API** shown through reusable React components
- 🔎 Location search, recent searches, °C/°F conversion and loading/error handling

`React` `REST API` `OpenWeatherMap` `Responsive UI`
